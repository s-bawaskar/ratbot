🐀 RATBOT — Privacy Policy

Last updated: September 2026

What we store

To run the game, RATBOT stores, per Discord server:

  • Your Discord user ID (not your username, email, or any other Discord account details)
  • Your in-game state: Modak balance, Mushaks caught, achievements unlocked, festival progress, and command cooldown timestamps

This data is scoped separately per server — your progress in one server has no effect on any other.

Message content

In channels an admin has set up for spawns, RATBOT reads message text in real time only to detect the catch keyword (and a couple of related joke reactions). Message content is not stored, logged, or retained — it is checked and discarded immediately.

What we don't do

We do not sell, share, or use your data for advertising. We do not collect data from channels the bot hasn't been set up in beyond what Discord itself provides for normal bot operation (channel and server IDs needed to respond to commands).

Third parties

Game data is stored with a database hosting provider (Neon) solely to run the service. It is not shared with any other third party.

Data deletion

To request deletion of your data, contact the bot owner via the /contactgod command in Discord.
